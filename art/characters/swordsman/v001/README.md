# Мечник — основа v001

Редактируемая стилизованная модель по пользовательскому концепту. Это первая объёмная основа для проверки силуэта и смены одежды, а не финальная игровая модель.

## Открыть

`swordsman_modular_v001.blend` — исходник Blender 5.2.2. Откройте через File → Open. Сохраните свою текущую сцену перед заменой файла.

Превью: `preview_front.png`, `preview_back.png`, `preview_alternative.png`.

## Менять одежду и оружие

В Outliner коллекции `10` и `11` — два варианта верха, коллекции `50` и `51` — два меча. Для каждого типа показывайте только один вариант. Для полноценного переключения нужно менять видимость и во viewport, и в render.

В файле есть текст `SWAP_EQUIPMENT.py`. Откройте его в Text Editor, задайте `TOP = 'jacket'` вместо `'longcoat'` и/или `WEAPON = 'relic'` вместо `'longsword'`, затем нажмите Run Script. Скрипт переключает оба типа видимости. В интерфейсе Python Console также можно выполнить:

```python
exec(bpy.data.texts['SWAP_EQUIPMENT.py'].as_string().replace("TOP = 'longcoat'", "TOP = 'jacket'"))
```

Отдельные модули: верх, штаны, перчатки, сапоги, волосы и открытые части тела. `Body_Covered` — скрытая геометрия для примерки; не включайте её поверх одежды.

## Скелет

Один `Rig_Swordsman`, 22 кости. Одежда привязана к нему. Оба меча используют `Socket_Weapon_R`, привязанный к правой кисти. Направление взгляда: -Y, вверх: Z, единицы: метры. Основа имеет A-позу. Движение пол кафтана предусмотрено двумя отдельными костями.

## Проверено и ограничения

`build_report.json` содержит состав и количество геометрии; `validation_report.json` — результаты повторного чтения .blend, проверки весов, крепления мечей и смены модулей.

Топология и веса предварительные: модель состоит из отдельных геометрических участков, места сгиба потребуют доработки. Пальцы пока не имеют отдельного рига. Материалы однотонные, нет финальной UV-развёртки, текстур, боевых анимаций и подтверждённого импорта в Unity. Не использовать как финальный ассет без этих этапов.

Скрипт воспроизведения: `tools/blender/build_swordsman.py` от корня проекта. Повторный запуск перезаписывает файлы v001; ручные изменения сохраняйте новой версией. Геометрия создана локально скриптом, без платной генерации и сторонних моделей. Концепт предоставлен пользователем; права на него отдельно не устанавливались.
