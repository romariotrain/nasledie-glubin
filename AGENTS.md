# Character asset work

For the accepted Unity prototype baseline, start with `docs/production/HANDOFF.md`.
The reusable iteration protocol is `docs/production/AGENT_WORKFLOW.md`; the review
and proposed next steps are in `docs/production/README.md`. These documents do not
authorize automatically installing tools or executing the entire roadmap.

When the user supplies character concepts and an animation list, follow
`tools/character_pipeline/README.md` and its request template. Read the applicable
game-asset-production skill. Use the installed local Hunyuan/Blender workflow and
preserve all source art and previous versions. The user may supply requirements in
ordinary language; translate them into the job specification yourself.

Do not treat swordsman-specific landmarks, rig dimensions or animation scripts as
generic character anatomy. Adapt them and inspect the results. Save input hashes,
parameters, previews and validation evidence. Distinguish generated shape, technical
export checks, visual review and target-engine validation. Never report an unrun
stage as passed or silently replace multiview generation with single-view.
