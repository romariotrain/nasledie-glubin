# Гильдия и экономика

## Что есть в гильдии
- **Золото и ресурсы**, вынесенные из подземелья.
- **Продажа** ненужных сокровищ.
- **Покупка постоянных улучшений.**
- **Хранение экипировки** между забегами.
- **Зал артефактов** — коллекция легендарных артефактов с постоянными бонусами. Артефакт не теряется вместе с героем, если его успели вынести.
- **Подготовка следующего героя.**

Гильдия — меню, а не градостроительный симулятор.

## Специализация оружия
В гильдии игрок развивает не сборку на конкретный забег, а предпочтительный стиль игры. Например, у длинного меча несколько направлений:
- **Мастерство** — больше урона, усиленное завершающее комбо.
- **Техника** — выше скорость атак, короче промежутки между ударами.
- **Разрушение** — больше урона по группам, сильнее отбрасывание.

Не обязательная линейная прокачка: игрок выбирает специализацию и постепенно открывает варианты внутри неё. Часть улучшений требует ресурсов, найденных в подземелье. Новые виды оружия тоже открываются и развиваются здесь.

## Постоянные бафы артефактов
Наследие делает игру легче со временем, а игра должна оставаться сложной. Поэтому часть бафов лучше делать не числовыми: дополнительный выбор награды, шанс сохранить часть добычи после гибели, новая возможность — а не только «+10% здоровья».

## Возможные постройки
*Для первой версии — не больше трёх.*
| Постройка | Назначение |
|---|---|
| Кузница | Новые виды оружия, улучшение экипировки |
| Тренировочный зал | Тренировки и варианты развития |
| Библиотека | Записи экспедиций, сведения о врагах и боссах |
| Школы мастеров | Передача и развитие техник наставников |
| Зал артефактов | Постоянные бафы |
| Лазарет | Лечение физических ран за ресурсы; возможно — редкий способ избежать окончательной гибели |
