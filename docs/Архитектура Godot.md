# Архитектура Godot

*Черновик: уточнять по ходу этапа 1 [[MVP и план разработки]].*

## Основа
- Godot 4.x, **типизированный GDScript** (`var hp: int`, `func hit(dmg: int) -> void`): ошибки ловятся раньше, код быстрее.
- Обычный 2D с сортировкой по Y (`y_sort_enabled` на узле мира) — этого хватает для камеры ¾, изометрические тайлы не нужны.

## Сцены
| Сцена | Узел | Заметка |
|---|---|---|
| Player | `CharacterBody2D` | Простой конечный автомат: idle, move, attack, dodge, hurt |
| Enemy | `CharacterBody2D` + `NavigationAgent2D` | Преследование по комнате из коробки |
| Hitbox / Hurtbox | `Area2D` | Удар — хитбокс, получение урона — хёртбокс; урон считается при пересечении |
| Projectile | `Area2D` | Снаряды, молнии, зоны |
| Room | отдельная сцена-шаблон | `Marker2D` для выходов и точек появления врагов |

## Предметы и эффекты
- Данные предмета — `Resource` (`.tres`): характеристики, теги, список эффектов. Как конфиг или DTO.
- Оружие и способности — тоже `Resource` с параметрами; модификатор способности — эффект, который подписывается на события *этой* способности (`ability_used`, `ability_hit`).
- **Шина событий боя** — autoload с сигналами (`hit`, `crit`, `kill`, `dodge`, `damaged`…). Эффекты подписываются на нужные события: обычный pub/sub.
- Счётчик глубины цепочки в событии: эффект, вызванный эффектом, не запускает реакции бесконечно → [[Предметы и синергии]].

## Состояние и сохранения
- Два слоя состояния: **забег** (текущий герой, найденное) и **мета** (гильдия, артефакты, наставники, вынесенное).
- Сохранение — в `user://` через `FileAccess` (JSON) или `ResourceSaver`.
- Autoload-синглтоны: `CombatEvents`, `GameState`, `SaveManager`.

## Структура папок
```
res://
  autoload/      CombatEvents, GameState, SaveManager
  scenes/
    player/
    enemies/
    rooms/
    ui/
  data/
    items/       .tres предметов
    enemies/
```
