# MVP — Наследие глубин

Не список всех желаемых возможностей, а последовательность проверок. Каждый этап заканчивается вопросом: ответ «нет» — не идём дальше, а чиним.

## Этап 1. Проверка боя
- [ ] Персонаж перемещается по арене, камера ¾
- [ ] Длинный меч: комбо из трёх ударов, рывок с неуязвимостью, способность «Пронзающий выпад» → [[Мечник]]
- [ ] Есть один обычный противник
- [ ] Есть получение и потеря здоровья
- [ ] Можно умереть и начать заново
- [ ] Хитстоп, вспышка, отбрасывание, тряска экрана

**Вопрос:** приятно ли две минуты просто двигаться и драться без всяких улучшений? Ощущаются ли удар, выпад и рывок по-разному?

## Этап 2. Проверка билдов
- [ ] Вторая способность — «Круговой разрез»
- [ ] Пара модификаторов на каждую способность (огненный след, волна энергии…)
- [ ] Несколько пассивок всех четырёх типов, в том числе «Сердце пламени»
- [ ] Работают эффекты при критическом ударе и убийстве
- [ ] Выбор пассивки после комнаты, улучшение способности после босса
- [ ] Есть хотя бы одна синергия, заметно меняющая бой

**Вопрос:** появляются ли комбинации, которых я не планировал? Чувствуется ли, что герой стал другим, а не просто сильнее?

## Этап 3. Проверка забега
- [ ] Есть 5–6 комнат
- [ ] Есть обычные и элитные противники
- [ ] Есть босс
- [ ] Награды частично случайны
- [ ] Работают смерть и эвакуация с привала

**Вопрос:** задумываюсь ли я на привале, идти дальше или выходить?

## Этап 4. Проверка долгосрочного прогресса
- [ ] Можно вынести добычу
- [ ] Можно потерять снаряжение при гибели
- [ ] Можно купить одно улучшение гильдии
- [ ] Один артефакт с постоянным бафом
- [ ] Две раны — одна физическая, одна психологическая — и их лечение в лазарете
- [ ] Прогресс сохраняется после перезапуска игры

**Вопрос:** после гибели хочется начать снова, а не закрыть игру?

## Этап 5. Наследие
- [ ] Есть один наставник
- [ ] Можно передать один особый навык будущему герою
- [ ] Навык влияет на доступные сборки

**Вопрос:** хочется ли вернуться живым ради наследия?

## Критерий успеха MVP
После нескольких забегов игроку хочется начать следующий, потому что он хочет проверить новую комбинацию предметов или попробовать более глубокий спуск.
